# Content Director Experiments

Initial experiments compare exactly two variants and one declared variable:
source family, hook family, prompt pattern, audio profile, or posting window.
Creator, account, intent, observation cohort, and publication-window
comparability remain controlled unless that one field is the declared variable.

Assignment is deterministic and receipt-bound. Every experiment stores its
hypothesis, variants, assignments, deterministic seed, required 24-hour cohort,
outcome links, and limitations. A two-item result is an observed difference,
not causal proof. Missing observations remain missing.

An experiment is rejected when it changes source, prompt, caption, audio,
timing, or account together. Operator review controls activation and
interpretation. Losing a variant blocks interpretation; it does not convert the
remaining item into a winner.
