# Creator OS Decision Inventory

This is the implementation-time map from an operator request to a measured
published Reel. “Operational proof” distinguishes existing real production
evidence from this branch's fixture-only planning proof.

| Decision | Owner / implementation | Selection and scope | Receipt / proof / missing context |
|---|---|---|---|
| Creator | operator + Campaign request | operator supplied; creator-specific; deterministic | create/plan receipt; real Stacey path exists |
| Account | operator scope, then Campaign account projection | plan rotates only healthy scoped accounts; account-specific | item account state; multi-account planning remains fixture-proven |
| Intent | operator for normal create; plan policy for a plan | supported non-talking intent set; static configurable mix | plan item receipt; real passive path exists |
| Source | Campaign production lane and Content Director | approved creator inventory; learned ordering only when supervised; deterministic least-used cooldown | source ID/SHA in create and plan receipts; source cooldown is fixture-proven |
| Prompt pattern | Campaign learning consumer | approved imported patterns; supervised creator/account/intent scope | recommendation and plan decision receipts; one real sample is insufficient |
| Hook | Campaign approved pattern/caption bank | selected within approved family; creator/account/intent scoped | pattern ID; adaptive production improvement unproved |
| Caption | Campaign/ThreadsDashboard | existing caption-bank/export behavior; not invented by planner | export lineage; planner does not rewrite it |
| Overlay | Reel Factory placement policy | deterministic safe-zone/preset behavior | placement decision; unchanged |
| Visual recipe | Campaign production policy | Higgsfield-only; Kling 3 pinned passive default, Seedance reviewed alternative | generation recipe/provider receipt; unchanged |
| Duration | Content Director policy then production recipe | deterministic five-second target within recipe support | item desired duration; real generation path proven separately |
| Audio eligibility | Campaign audio policy | non-talking only; exact track near finishing | audio profile/receipt; unchanged Audio Radar behavior |
| Track | Audio Radar | current eligible cache/discovery ranking, cooldown, creator/account constraints | exact music ID/track SHA after selection; not reserved by planner |
| Segment | Audio Radar finishing path | duration-compatible and batch-unique | segment boundaries/SHA and final MP4 binding; unchanged |
| Posting window | Content Director proposal; ThreadsDashboard final authority | account-specific deterministic fallback unless eligible supervised timing exists | proposal source layer; real schedule use unproved |
| Trial vs regular Reel | ThreadsDashboard/operator policy | outside planner authority | dashboard draft/publication evidence; planner records no invented choice |
| Campaign/cohort | Campaign and ThreadsDashboard metric history | plan/item/experiment plus 1h/24h/72h cohorts | cohort rows; 1h advisory, missing never zero |
| Generation count | operator/plan output count | bounded 1–100; plan default from product policy | plan and independent job receipts |
| Spend cap | operator | explicit signed ceiling; planner estimates but cannot authorize | estimate/authorization/actual variance receipts |
| Export | Campaign existing export adapter | approved-only and exact identity; plan command currently preview-only | HMAC/final SHA required; no export performed here |
| Scheduling | ThreadsDashboard | final account authorization and schedule mutation | ThreadsDashboard schedule ID; none created here |
| Publication | ThreadsDashboard | real platform request plus Instagram media ID | queue receipt alone is insufficient; none created here |
| Metric cohort | ThreadsDashboard history + Campaign snapshots | account/content/age specific | 1h/24h/72h rows; real plan-linked cohorts pending rollout |
| Learning recommendation | Reference provenance + Campaign supervision | at least three valid equal-age results; explicit approval | pack/fingerprint/recommendation/decision receipt |

Before this work, the operator manually coordinated inventory review, create
commands, media review, export, schedule, metrics, learning refresh, and the
next create. The Content Director now joins plan, scoped execution, review
context, export preview, cohorts, and replanning under one versioned receipt
chain. Spend authorization, media approval, final scheduling, publication, and
learning approval remain separate operator boundaries.
